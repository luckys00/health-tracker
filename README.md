# 🌿 Health Tracker

A modern, responsive, and feature-rich web application designed to help users monitor, analyze, and improve their daily health habits. Track your physical activities, sleep quality, water intake, and nutritional habits in one unified, elegant dashboard.

![Health Tracker Banner](https://images.unsplash.com/photo-1517838277536-f5f99be501cd?q=80&w=1200&auto=format&fit=crop)

---

## 🚀 Features

- **📊 Comprehensive Dashboard**: Get a quick overview of your daily stats including steps, calories burned, sleep hours, and water intake.
- **🏃 activity Logger**: Log workouts with details like duration, intensity, and activity type (running, cycling, yoga, etc.).
- **🍏 Nutrition & Hydration Tracker**: Log meals, track calorie/macronutrient distribution, and set reminders for hydration.
- **😴 Sleep Analyzer**: Track sleep phases, duration, and receive insights on sleep quality over time.
- **📈 Interactive Progress Charts**: Visualize your weekly, monthly, and yearly progress with dynamic, interactive charts.
- **🌙 Glassmorphism UI / Dark Mode**: A beautiful, premium interface that is fully responsive and supports sleek transitions.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom properties, CSS Grid, Flexbox), Javascript (ES6+)
- **Charts**: [Chart.js](https://www.chartjs.org/) for beautiful, responsive data visualizations.
- **Storage**: LocalStorage / IndexDB for offline-first data persistence.
- **Icons**: Lucide Icons or FontAwesome.

## 💻 Local Setup Instructions

Follow these simple steps to set up the project locally:

### Prerequisites

You need a web browser and a local development environment. If you want to use npm/Vite:
- [Node.js](https://nodejs.org/) (v16.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) (usually bundled with Node.js)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/luckys00/health-tracker.git
   cd health-tracker
   ```

2. **Initialize dependencies (if using a build tool)**:
   ```bash
   npm install
   ```

3. **Run the application**:
   - For a basic static setup, simply open `index.html` in your browser.
   - For a development server (Vite/Node):
     ```bash
     npm run dev
     ```
